# California Housing Regression and Regularization

## Overview
Compare Linear Regression, Ridge, Lasso, and Elastic Net for predicting median house values. The notebook uses leakage-safe preprocessing, five-fold cross-validation for tuning, and a held-out test set for final evaluation.

## Dataset
Place `housing.csv` beside the notebook. It must include `median_house_value` and `ocean_proximity`. The data file is not included; obtain it from the course-provided source and check its terms before sharing.

## Run
Install dependencies with `pip install -r requirements.txt`, open the notebook in Jupyter or Colab, and run all cells from top to bottom.

## Methodology
An 80/20 split is used. Numeric data is median-imputed and standardized; categorical data is imputed and one-hot encoded. All preprocessing is fitted inside the pipeline in each CV fold. Five-fold CV selects regularization settings using RMSE. Final metrics include RMSE, MAE, R², coefficient norms, and non-zero coefficient counts.

## Reproducibility and privacy
Metrics are generated by executing the notebook. Do not commit personal registration details, private notebook links, or data files without permission.
